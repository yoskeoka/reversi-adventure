phase 0–59 の候補は、既存の採用モデル `0019-20261020-02` との独立した20局で
6勝14敗、6.0/20点となり、`not-improved-at-pilot-scale` で終了した。
200局への延長は行わず、この候補は未採用である。0018の受け入れ結果ではない。
対戦設定は深さ12、空き16マス以下で完全読みである。

phase 0 は暫定固定ゼロであり、0–9の学習では validation が phase 0–2、test が
phase 0–3 で取得できなかった。全 phase に表があることは全 phase の検証データが
揃っていることや、従来の full pilot と同一の条件であることを意味しない。

## 保存範囲

直下の候補、manifest、report、receipt と `units/` は結合 root のコピーである。
`archives/` は新しい序盤 root、結合元5 root、結合 root をそれぞれ丸ごと gzip tar で
保存したものである。各 archive は同名の root directory を含む。完了局、露出情報、
生成 checkpoint、attempt のログと設定、学習途中の unit と report を含む。
ファイルの一覧と SHA-256 は `SHA256SUMS` を参照する。

元の root は checkout 外の `.local/reversi-ai-runs/` に残している。archive 内の
manifest は作成時の絶対パスを記録しており、原本を上書きせず別の場所に展開して
調査する。履歴の元入力、baseline、実行 binary、Oracle runtime など root の外にある
依存物は archive に含まず、この保存だけで完全な再実行や offline verify ができるとは
限らない。成果物の保存はモデルの採用を意味しない。
